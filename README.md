# Global-Sales-Performance-Interactive-Excel-Dashboard
## Project Overview
This project features a comprehensive Excel-based dashboard designed to track and analyze business performance across multiple global regions. The analysis covers **2,000 transactions** over a two-year period (January 2022 – December 2023), focusing on key financial metrics like Revenue, Profitability, and Expense management.

## Key Insights
* **Total Revenue:** $53.9M
* **Total Profit:** $20.4M (38% Margin)
* **Top Performing Region:** Africa (by transaction volume)
* **Primary Categories:** Analysis of R&D, Operations, Sales, Marketing, and HR departments.
* **Customer Segments:** Multi-segment analysis including SMB, Enterprise, B2B, and B2C.

## Features
* **Dynamic Slicers:** Filter the entire dashboard by Region, Product Line, and Payment Method.
* **Financial Trends:** Comparative analysis of Revenue vs. Expenses by Department.
* **Geographic Distribution:** Breakdown of transaction counts across Europe, North America, South America, Africa, and Asia-Pacific.
* **Profitability Analysis:** Evaluation of profit margins across different payment methods (Cash, Credit Card, PayPal, Bank Transfer).

## Technical Skills Demonstrated
* **Data Cleaning:** Handling raw transactional data and formatting for analysis.
* **Pivot Tables & Pivot Charts:** Summarizing large datasets for visual reporting.
* **Advanced Formulas:** Calculated fields for Profit and Discount impact.
* **Dashboard Design:** UI/UX principles for clear business communication.

## How to Use
1.  Download the `Excel dashboard 1.xlsx` file.
2.  Open in Microsoft Excel (Desktop version recommended for full slicer functionality).
3.  Use the slicers on the **Dashboard** sheet to interact with the data.

## Data Source
The dataset contains transaction IDs, dates, financial metrics, and categorical metadata for a global retail/services operation.
